Troubleshooting

This page documents issues I encountered while building my AWS cloud projects and how I resolved them.

S3 Access Denied

Enabled Static Website Hosting and updated the bucket policy to allow public read access.

IAM User vs Root User

Configured an IAM administrator account for daily AWS work instead of using the root account.

AWS CLI Configuration

Configured the AWS CLI using aws configure and verified the account with aws sts get-caller-identity.
